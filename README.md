# Dental Life – Landing Page de Clínica Odontológica

Landing page de uma clínica odontológica, feita com **HTML e CSS puros**. Apresenta os serviços e a equipe, e traz um formulário de agendamento de consulta.

> **Projeto de estudo**, sem fins comerciais e sem vínculo com nenhuma clínica real. Textos, avaliações e contatos são apenas demonstrativos.

🔗 **Ver online:** https://felipecsantos-dev.github.io/dental-life/

## Seções

Início · Números da clínica · Serviços · Sobre · Avaliações · Agendamento · Rodapé

## Tecnologias e recursos

- HTML5 semântico
- CSS3 com Grid, Flexbox e variáveis (`:root`)
- Layout responsivo com `@media`
- Menu fixo no topo (`position: sticky`)
- Google Fonts (Plus Jakarta Sans e Instrument Serif)
- SEO: meta tags, Open Graph e JSON-LD
- Git, GitHub e GitHub Pages
